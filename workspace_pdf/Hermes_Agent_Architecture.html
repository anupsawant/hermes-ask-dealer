Hermes Agent Architecture

User-facing agent runtime: orchestration core, tool layer, extensions, and persistence

Core Orchestration

  • • LLM reasons over the request and plans tool calls
  • • Batches independent calls, serializes dependent ones
  • • Verifies real tool output before reporting done
  • • Routes long-running work to subagents or cron

Tool Layer

  • • Browser, terminal/code exec, file read/patch
  • • Web search/extract, vision, text-to-speech
  • • Deferred catalog loaded on demand via tool_search
  • • clarify() pauses for user decisions mid-task

Extensions & Persistence

  • • Skills: task-specific know-how loaded on demand
  • • Plugins: installable capability packs
  • • Memory + session search persist across sessions
  • • Cron runs scheduled/background automation
